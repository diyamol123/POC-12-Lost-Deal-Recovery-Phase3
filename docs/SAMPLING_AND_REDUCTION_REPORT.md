# Sampling and Reduction Report

## Source Dataset

The Phase 2 synthetic CRM dataset contains 20 records.

Source record range:

`CRM-001` through `CRM-020`

## Sampling Decision

No sampling reduction was performed.

All 20 source records were retained in the Phase 3 canonical package.

## Reason

The complete supplied dataset is already below the Phase 3 default limits:

- Maximum sample rows: 10,000
- Maximum columns: 50

The source contains:

- 20 records
- 13 source fields

Retaining the complete dataset preserves the available:

- date coverage
- lost-deal reasons
- products
- stages
- priorities
- companies
- competitors
- business segments
- locations
- teams

## Sampling Method

No random sampling was required.

Therefore no sampling seed was required.

The pipeline does not use `df.head()` or another arbitrary first-N-row reduction.

## Reduction

No records were removed.

No source categories were intentionally removed from the source sample.

The canonical schema does not have dedicated fields for every source attribute. Fields without a direct canonical representation are documented in:

`docs/CANONICAL_DATA_MAPPING.md`

## Retention

Source sample:

`data/source-sample/source_sample.csv`

Canonical dataset:

`data/canonical/intelligence_data.csv`

Both contain all 20 available records.

## Reproducibility

The source sample is preserved as a separate input artifact.

The canonical dataset is generated by:

`scripts/data_pipeline/standardize_data.py`

The canonical package uses the fixed data version:

`phase3-v1.0.0`

## Data Limitation

This package represents the complete supplied Phase 2 synthetic CRM dataset. It should not be interpreted as a complete production CRM export because no production CRM export or external operational dataset was supplied.
